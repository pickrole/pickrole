# 0004. UI in Svelte 5, TypeScript and Tailwind, developable without a backend

- Status: accepted
- Date: 2026-09-26

## Context

The UI is small but stateful (session, accounts, active profile, loading states). It has to be quick to change,
including by people without access to an AWS setup with IAM Identity Center.

## Decision

Use **Svelte 5** (runes), **TypeScript** and **Tailwind CSS v4**, built with Vite. Every backend call goes through
`frontend/src/lib/api.ts`, which uses a mock (`mock.ts`) when the page isn't running inside Wails.

## Alternatives considered

- **React or Vue**: would work, with more code and more runtime for a UI this size.
- **Types generated by `wailsjs`**: would tie the frontend to generated code. The types are written by hand in
  `types.ts`, mirroring the Go structs.

## Consequences

- `npm run dev` shows the whole UI with sample data, without Go, Wails or AWS.
- Changing a struct exposed to the UI means updating the Go struct, `types.ts` and the mock.
